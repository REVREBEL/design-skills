# Editorial design critique

## Input
Collect user goal, target pages/states, brand references, screenshot or prototype, and constraints. When screenshots are unavailable, restrict findings to source-level design and state the limitation.

## Method
1. Describe current visual hierarchy, visual rhythm, layout grids, type roles, and imagery composition without prescribing changes.
2. Check whether the design is specific to the brand or generic luxury styling.
3. Trace key task paths: find availability, understand accommodation, compare rates, see total price/policies, and continue checkout.
4. Audit states: loading, error, empty, unavailable, narrow mobile, keyboard, zoom, reduced motion.
5. Classify observations as objective failure, evidence-backed concern, or aesthetic judgment.
6. Prioritize findings by user impact, confidence, effort, and reversibility.
7. Propose fixes that preserve existing design intent; recommend validation for controversial trade-offs.

## Output
Evidence annotated by screen/component; strengths worth preserving; prioritized critique; design changes with rationale; test plan; unknowns. Never claim an inaccessible interface was tested.
