# Brand Benchmark: Aman Resorts
Atmospheric stillness, spatial confidence, single dominant decision per viewport, persistent floating search capsule.


## Preserved benchmark analysis

### Brand 1: Aman Resorts (Atmospheric Stillness & Spatial Confidence)
*   **Core Philosophy**: Extreme visual restraint, environmental atmosphere, and unhurried spatial confidence.
*   **UI Execution Patterns**:
    *   **Generous Semantic Negative Space**: Padding and margins set at 2x to 3x standard e-commerce grid standards (`padding: 120px 0`), forcing focus onto singular visual assets.
    *   **Minimalist Search Capsule**: Single-line floating booking bar on desktop that expands only upon active user intent via slide-over progressive drawer.
    *   **Zero Interruption Modals**: Complete ban on pop-ups, newsletter captures, discount banners, and exit-intent prompts.
*   **Pattern Transfer Rule for AI**: When designing property landing pages or suite display pages, limit each viewport step to **one dominant proposition**. Use environmental media to build spatial desire before introducing transactional inputs.
