# Example: asset manager overview
Illustrative brief: owner monitors eight authorized hotels, evaluating occupancy/ADR/RevPAR, budget variance and outliers. Prefer portfolio exception list + period comparison with switchable denominators and view-as-of timestamp. Primary actions navigate to property detail; no write control without permission. Responsive mobile default is exception triage with expandable property rows. Acceptance: source basis visible, weighted KPI aggregates, no unauthorized properties, N/A for absent eligible inventory, keyboard access and clear stale signals.
