# Pattern: state and feedback matrix
Static labels: visible/default, and interactive focus/hover only if actually clickable. Buttons: default/focus/disabled/loading/pressed as applicable. Inputs: valid/invalid, read-only, disabled, pending and assistance. Data sources: loading, empty, partial, stale, error, forbidden, offline, conflict. Writable workflows: draft, submitting, authoritative success/failure, audit. Define states by component responsibility; do not require every primitive to implement a meaningless global set. Error copy should explain whether the user can retry, change input, or contact support. Never expose secrets in error surfaces.
