# UI Pattern: Experiential Dynamic Filters
Horizontal filter pill bar updating accommodation collections smoothly without page reloads.


## Expanded pattern specification

## 8. Experiential Dynamic Filters & Curated Package Cards (`experiential-filters`)

### Filter Interface
* Horizontal pill bar allowing guests to filter accommodations by experiential attributes:
  * *Private Pool / Onsen*
  * *Mountain / Ocean Sightlines*
  * *Multi-Bedroom Suites*
  * *Spa & Wellness Packages*

### Interaction & Feedback
* Selecting a filter updates the room collection immediately using smooth grid reflows without page reloads.
* Empty filter states show helpful guidance with a single-click "Reset Filters" action button.
