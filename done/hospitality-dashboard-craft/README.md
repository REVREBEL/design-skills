# Hospitality Dashboard Craft v3.2
Install this **entire folder**, not just SKILL.md, in a compatible agent skills directory. `SKILL.md` routes to substantive references, procedural workflows, patterns, examples, and an executable Python metric fixture harness. The package is an agent skill and reusable implementation patterns, **not** a deployed dashboard, a vendor connector, or a WCAG certification.

## Quick start
Ask: "Audit this hotel's revenue dashboard for metric accuracy, minimalism, accessible tables, and Tailwind v4 integration." Provide existing code, a relevant screenshot, or specs when possible. For blank-slate design, specify decision-makers and example decisions.

## Validation
`python3 scripts/check_metrics.py` tests reference metric functions against `evals/metric-fixtures.json`.
`python3 scripts/validate_package.py` checks skill structure, links, JSON and control characters.
Tests are local model arithmetic/structure checks, not live vendor integration or end-to-end app tests.

This v3.2 package supersedes the v3.1 source specification. Earlier formula and system-authority mistakes have not been carried into the governing reference material.
