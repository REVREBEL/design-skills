# Workflow: test and handoff
Validate numeric fixtures; inspect 0 and missing cases; test role/tenant isolation including URL tampering; verify loading/partial/stale/forbidden/error/conflict conditions where applicable. Test keyboard from start to finish, semantic table and chart alternatives, focus on dialogs and sticky UI, reduced motion and 200% zoom. Confirm visual design at representative widths and density settings. Run unit/typecheck/integration/e2e and axe where available; manual WCAG and data checks remain necessary. Record pass/fail/not-run for each, precise evidence, dependencies, outstanding risks and artifact lifecycle stage. Do not label production verified absent a real deployment and real checks.
