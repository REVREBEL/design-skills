# Pattern: property/portfolio switcher
Expose current scope in persistent context, not only a logo. Offer searchable authorized property list, optional regions/brands, breadcrumbs for hierarchy, distinct portfolio/all-properties mode, and visible warnings before high-impact cross-property actions. Preserve permitted date/segment filters when switching if semantics match, otherwise clear them with explanation. Fetch server-authorized data for each scope, invalidate cached results on switch, and test URL parameter tampering. For keyboard use combobox/listbox semantics or native select, not custom unlabeled divs.
