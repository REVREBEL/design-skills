# Design Styles

Single-entry-point master skill for visual style guidance. Install the ZIP as a plugin: its root contains `skills/design-styles/SKILL.md`. The 14 original specialist guides are retained in `guides/`, each as `guide.md`, and are invoked internally by the master router.

For new styles: add a guide in `guides/<style>/guide.md`, update the route table in `SKILL.md`, and keep the archive to exactly one `SKILL.md`.
