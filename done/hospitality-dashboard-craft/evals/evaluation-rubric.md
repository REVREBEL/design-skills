# Skill evaluation rubric (100 points)
Domain correctness and provenance 30; decision-centered IA and visual craft 20; framework/component correctness 15; accessible keyboard and screen reader behavior 15; state, permissions and integration integrity 15; truthful testing/handoff 5.

Automatic failure for fabricated live data/vendors, undefined ratio shown as valid zero, unauthorized cross-property records, claiming production verification without tests, incorrect revenue basis, or recommending unsafe offline financial writes as default. A proposal may legitimately report unverified constraints; it should not fail for being honest about missing access. Assess concept/design/implementation deliverables against the correct lifecycle stage.
